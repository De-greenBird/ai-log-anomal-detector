## 📝 Overview
This repository contains a Python-based security tool that uses **Machine Learning** to identify malicious system logs or cyber attack patterns. By processing log lines using Natural Language Processing (**TF-IDF**) and training an **Isolation Forest** model, the system successfully flags anomalous behaviors (like SQL injections or unauthorized directory scanning) without relying on rigid, pre-defined rules.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Libraries:** Scikit-learn, Pandas, NumPy

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute the detector:
   ```bash
   python detector.py
   ```
